# Market Research Checklist

Use during `product-bootstrap` and any vertical expansion.

## Time box

- New product: 45–90 minutes of agent research before code
- New feature in known market: 15–30 minutes competitor/feature scan

## Sources (minimum)

1. Web search (Tavily research) — category, incumbents, pricing hints
2. GitHub search — OSS alternatives, stars, recency, license
3. Product homepages of top 3 — positioning, features, CTAs
4. HN / launch threads when category is public
5. App stores / G2 / Product Hunt only if category lives there

## Competitor table fields

| Field | Why |
|-------|-----|
| Name | Identity |
| Type | OSS / SaaS / both |
| Traction | stars, funding, users if known |
| Core promise | their one-liner |
| Strengths | honest |
| Weaknesses / gaps | our wedge candidates |
| License / pricing | constraints |
| Source URLs | no memory-only claims |

## Kill / pivot triggers

- Clear leader with open source + hosted that matches 90%+ of P0
- No reachable distribution for the wedge
- Regulation blocks the data you need
- User cannot state differentiation in one sentence

## Deliverable

`docs/market-brief.md` with problem, user, alternatives (≥3), differentiation, risks, sources.
