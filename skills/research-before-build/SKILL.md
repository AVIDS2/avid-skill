# Research Before Build

Default bias: **find, don't found** — when research is cheap relative to build cost.

## Advisory

- Run a time-boxed scan (Tavily/GitHub/existing skills/MCPs) before large self-builds.  
- **Skip or shrink** for glue code, project-local helpers, or user-approved spikes.  
- Decision: reuse / wrap / build — "build" needs a short reason when options exist.

## Output (lightweight)

Capability → options (if any) → decision → why → sources (when you searched).
